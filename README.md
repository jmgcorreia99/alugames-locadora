## Descrição 💬

AluGames é uma plataforma de **aluguel de jogos de tabuleiro** (boardgames). O sistema permite que os usuários escolham jogos disponíveis, aluguem ou devolvam, e acompanhem o status do seu pedido. Este projeto foi desenvolvido para facilitar o acesso a jogos de tabuleiro para diversão em grupos, proporcionando uma experiência rápida e prática. 🎉

## Funcionalidades 🚀

- **Visualização de jogos**: Navegue por uma lista de jogos disponíveis 🎮.
- **Aluguel**: O usuário pode alugar jogos com facilidade 📦.
- **Devolução**: O usuário pode devolver jogos alugados diretamente na plataforma 🔄.
- **Controle de status**: A plataforma altera dinamicamente o status dos jogos entre "Alugar" e "Devolver" 🔄.

## Tecnologias 🔧

Este projeto foi desenvolvido utilizando as seguintes tecnologias:

- **HTML5**: Estrutura básica da página 🧱.
- **CSS3**: Estilização e design responsivo 🎨.
- **JavaScript**: Lógica de interação, manipulação de eventos e controle de estado dos jogos 🖥️.

## Como rodar o projeto localmente 🔥

Para rodar o projeto localmente, siga os passos abaixo:

### 1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/alugames-locadora.git
```

### 2. Navegue até a pasta do projeto:

```bash
cd alugames-locadora
```

### 3. Abra o arquivo `index.html` no seu navegador:

Simplesmente abra o arquivo `index.html` no navegador de sua escolha para começar a usar o sistema de aluguel de jogos.
